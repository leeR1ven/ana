# 后续规划（前额叶进阶，暂不实现）

记录时间：2026-10-22

## 1. 工作记忆 / 目标保持（A → B → C 链）

**现状**：只有 `A（感觉）→ C（运动）` 的单环。
球一消失，驱动它的状态就变了，追球的方向就丢（实测：消失后仍会动 0.12–0.18 米，但方向反了）。

**目标**：
```
A（看到球）→ B（记住"往那边追"）→ C（运动区继续执行）
```
即使 A 不再激活，**B 保持激活**，狗继续朝球消失的方向追。

**已验证的机制**（够用，缺的是"放在哪"）：
- 一组神经元 + 内部自兴奋回路，触发后**撤掉输入仍保持满活性**（实测 1.000 → 1.000）；
- 目前这组在运动区里，等于"运动区自己保持"，不是真正的 B。

**下一步要做的**：
1. 在 `build.py` 里给**运动区之外**（前额叶）加一组"保持单元"（16~32 个）；
2. 连线：感觉 L5 → 保持单元（阈值较高，需要明显刺激才触发）；
   保持单元 → 自身（自兴奋，双稳态）；
   保持单元 → 运动区（权重适中，驱动持续动作）；
3.  навык：`pursue` —— 球出现后消失，要求在 100 拍内继续朝球消失方向走 >0.10 米。

## 2. 动作链（A→B→C 的行为层）

**现状**：单步动作（看到就做）。

**目标**：动作之间能串起来，例如：
- 看到障碍 → 绕行 → 继续前进；
- 起身 → 站稳 → 走；
- 追球 → 球消失 → 在最后位置附近搜索。

**做法**：保持单元的输出接到下一个动作的触发条件（序列记忆），
本质仍是"自兴奋 + 阈值"的组合，不需要新机制。

## 3. 前额叶对运动的微调

**现状**：已验证"输入变一点，动作形态就变"（形态相关 0.19），说明余地存在。

**目标**：前额叶根据目标位置/距离，对运动程序做**幅度与轨迹的微调**，
而不是只靠全局调制（`motor_mod`）整体放大缩小。

**做法**：把"目标相对位置"作为一路额外输入接到运动区，
让同一个动作程序在不同目标下产生不同的落点（`goto2` 已经是雏形，差异只有 2 厘米，需要加强）。

## 原则（这一阶段学到的）

1. **先验证题目可达**，再谈难度；
2. **先量清楚**（打印中间层活性/距离/斜率），再改代码；
3. **不要加多余机制**——动作是运动区复杂连接的结果，不是靠额外通路堆出来的；
4. **能靠结构解决的，不要靠调参**（时钟、躯干执行器、蓝通道抑制都是结构改动，一次就通）。

## 补充：B 是什么（2026-10-22）

B **不是某一个神经元**，而是**一群神经元共同构成的"概念范围"**——
类似文字网络里一个词的分布式表征：由一片神经元的**相对激活模式**承载，
不是"第 1234 号神经元 = 追球"。

所以实现时要按"群体"来做：
- 一个 B 对应一组单元（几十个），激活时**整组进入同一个吸引子**；
- 同一个 B 可以由不同输入从不同方向激活（只要落进同一个吸引子盆地）；
- "保持激活"= 该组落在吸引子里，稳定不走；
- 不同 B 之间靠**重叠与竞争**区分（追球 vs 追声音，是两个部分重叠的群体）。

这也解释了为什么单个神经元做不出记忆：记忆是**群体状态**，不是单点状态。
之前的验证用 32 个单元的自兴奋组，方向是对的（群体），
但更应该做成"多个吸引子共存、由输入决定落进哪个"。

## 4. 眼位→概念→动作的链（2026-10-22 记录）

**使用者给的机制**：
> 眼睛往下看时，特定的（眼）肌肉被激活 → 这些肌肉信号再激活特定前额叶概念神经元
> → 概念神经元激活"蹲下/压低前身"的动作，方便观察地上的物体。

**要点**：眼睛的**姿态本身**就是一种感觉信号（眼肌本体感觉），
它和视觉内容一样能触发概念，再由概念驱动身体动作。

**我们现在的状态**：

| 环节 | 状态 |
|---|---|
| 眼动（水平 pan） | ✅ 有反射（把目标拉到中心） |
| 眼动（垂直 pan，往上看/往下看） | ⬜ 未做 |
| 眼肌信号送回脑（作为感觉） | ⬜ 未做（现在的眼动是任务层算的，没进网络） |
| 前额叶"概念"单元 | ⬜ 未做（`NEXT_STEPS` 第 1 节） |
| 概念 → 蹲下 | ⬜ 身体压不下去（最低 0.265，`lie`/`crawl` 因此移除） |

**结论**：这条链要成立，需要三件事一起做：
1. 眼睛做成**两条肌肉**（水平/垂直），并由运动区输出驱动（而不是任务层反射）；
2. 眼肌的位置/用力作为**本体感觉**送回脑（proprio 通道）；
3. 前额叶概念单元（群体 + 吸引子）接收它，再驱动身体动作；
4. 同时身体要能**主动折叠腿**（蹲下），否则链的末端没有执行器。

## 5. 立体海马体（位置细胞）比时间环更好（2026-10-22 记录）

使用者：**原本打算做立体（3D）的海马体神经元，因为太复杂没做；其实它比时间神经元更好。**

道理：
- **时间神经元**只编码"何时"（一维、单调推进、一圈固定时长）；
- **位置细胞（place cell）**编码"在空间哪个点"，天然是**多维、可组合**的：
  同一个位置能由多条路径到达，位置之间的关系可以内插（认知地图）；
- 时间维其实可以**由空间位移导出来**（走了多远 = 时间 × 速度），
  所以位置细胞一套就同时支撑"在哪 / 何时 / 怎么走过去的"。

**为什么当时放弃**：3D 位置场 + 网格细胞需要额外的空间输入（本体的位移积分），
在那个阶段把架构复杂度推得太高。

**现在可以怎么做**（等身体能真正移动之后）：
1. 用本体感觉的速度积分得到"我走过的路径"（path integration）；
2. 用一小群 3D 位置细胞覆盖活动范围（每格一个位置，局部兴奋 + 全局抑制 → 单峰）；
3. 记忆挂到位置细胞上（而不是时间格）→ "在哪儿发生过什么"；
4. 追球记忆也就自然成立：球消失后，往"球最后出现的位置细胞"方向走。

**结论**：时间环是"临时替代品"，位置细胞是更正确的结构；
等步态真正跑通、狗能真正移动之后，优先换成 3D 位置细胞。

## 6. 链式神经元 → 海马体 → 赫布连接 = 短期记忆（2026-10-22 用户方案）

**用户方案**：
> 信号在不同区域激活后，通过链式神经元发给海马体；海马体再产生**赫布连接**——这不就有短期记忆了吗。

**完全可行，而且所需机制我们已经有**：

| 已有 | 在哪 | 说明 |
|---|---|---|
| 链式神经元 | `build.py` 各区 L1~L5 的链 | 每层向上汇聚，天然就是"信号逐级送到上游" |
| 可塑权重 | `engine.wp`（`w * sgn`） | 与 `w` 分开，专门给学习用 |
| 赫布式增强 | `consolidate.py:102` | `w[k] = min(1.0, v + lr·(1-v))`——共激活就增强，与"一起亮的会连起来"一致 |
| 分组管理 | `engine.group` | 可以给"海马体绑定边"单独一个组号，方便只让这组可塑 |

**缺的只有"海马体那个块"**：
1. 在 `build.py` 里加一个 `hippo` 块（**512 个单元**，固定数量，按用户要求），
   `region="hippo"`、`depth=0`；
2. 输入：从**各区 L5** 采样接入（视野权重高、触觉/本体低——和之前 `HippoBinder` 的强度分配一致）；
3. 这些边单独一个 `group`（例如 90），标记为可塑；
4. 每拍或每 N 拍做一次赫布增强：**共激活的（区域内容, 海马单元）对，权重上调**；
5. 之后"给一段内容"就能通过海马体重建另一段内容——这就是**短期记忆的读出**。

**为什么这比时间环好**：
- 不依赖"一圈固定时长"（时间环的致命问题）；
- 记忆是**内容到内容**的关联，而不是"内容挂到某个时间格"；
- 容量随赫布连接数增长，可以自然衰减/覆盖（短期）。

**实现顺序**：先做 1~3（结构 + 分组），验证"海马体单元会随输入活动"；
再做 4（赫布增强）验证"绑定后能看出关联变强"；最后做 5（读出）。
