# 后续规划（前额叶进阶，暂不实现）

记录时间：2026-10-22

## 1. 工作记忆 / 目标保持（A → B → C 链）

**现状**：只有 `A（感觉）→ C（运动）` 的单环。
球一消失，驱动它的状态就变了，追球的方向就丢（实测：消失后仍会动 0.12–0.18 米，但方向反了）。

**目标**：
```
A（看到球）→ B（记住"往那边追"）→ C（运动区继续执行）
```
即使 A 不再激活，**B 保持激活**，狗继续朝球消失的方向追。

**已验证的机制**（够用，缺的是"放在哪"）：
- 一组神经元 + 内部自兴奋回路，触发后**撤掉输入仍保持满活性**（实测 1.000 → 1.000）；
- 目前这组在运动区里，等于"运动区自己保持"，不是真正的 B。

**下一步要做的**：
1. 在 `build.py` 里给**运动区之外**（前额叶）加一组"保持单元"（16~32 个）；
2. 连线：感觉 L5 → 保持单元（阈值较高，需要明显刺激才触发）；
   保持单元 → 自身（自兴奋，双稳态）；
   保持单元 → 运动区（权重适中，驱动持续动作）；
3.  навык：`pursue` —— 球出现后消失，要求在 100 拍内继续朝球消失方向走 >0.10 米。

## 2. 动作链（A→B→C 的行为层）

**现状**：单步动作（看到就做）。

**目标**：动作之间能串起来，例如：
- 看到障碍 → 绕行 → 继续前进；
- 起身 → 站稳 → 走；
- 追球 → 球消失 → 在最后位置附近搜索。

**做法**：保持单元的输出接到下一个动作的触发条件（序列记忆），
本质仍是"自兴奋 + 阈值"的组合，不需要新机制。

## 3. 前额叶对运动的微调

**现状**：已验证"输入变一点，动作形态就变"（形态相关 0.19），说明余地存在。

**目标**：前额叶根据目标位置/距离，对运动程序做**幅度与轨迹的微调**，
而不是只靠全局调制（`motor_mod`）整体放大缩小。

**做法**：把"目标相对位置"作为一路额外输入接到运动区，
让同一个动作程序在不同目标下产生不同的落点（`goto2` 已经是雏形，差异只有 2 厘米，需要加强）。

## 原则（这一阶段学到的）

1. **先验证题目可达**，再谈难度；
2. **先量清楚**（打印中间层活性/距离/斜率），再改代码；
3. **不要加多余机制**——动作是运动区复杂连接的结果，不是靠额外通路堆出来的；
4. **能靠结构解决的，不要靠调参**（时钟、躯干执行器、蓝通道抑制都是结构改动，一次就通）。

## 补充：B 是什么（2026-10-22）

B **不是某一个神经元**，而是**一群神经元共同构成的"概念范围"**——
类似文字网络里一个词的分布式表征：由一片神经元的**相对激活模式**承载，
不是"第 1234 号神经元 = 追球"。

所以实现时要按"群体"来做：
- 一个 B 对应一组单元（几十个），激活时**整组进入同一个吸引子**；
- 同一个 B 可以由不同输入从不同方向激活（只要落进同一个吸引子盆地）；
- "保持激活"= 该组落在吸引子里，稳定不走；
- 不同 B 之间靠**重叠与竞争**区分（追球 vs 追声音，是两个部分重叠的群体）。

这也解释了为什么单个神经元做不出记忆：记忆是**群体状态**，不是单点状态。
之前的验证用 32 个单元的自兴奋组，方向是对的（群体），
但更应该做成"多个吸引子共存、由输入决定落进哪个"。
