# P3 实验日志：把大脑接到宇树 Go2

## 2026-10-21 打通部分

**身体接口**（`agi/body_go2.py`）：12 关节力矩 + PD 站姿 + 机体状态→五种感觉；
物理 500 Hz、大脑 50 Hz（一拍 10 个物理子步）。

**闭环实测**（`experiments/p3_go2.py`，full 规模，200 拍）：

| 指标 | 数值 |
|---|---|
| 每拍耗时 | 均值 10.0 ms / p95 11.8 ms（预算 20） |
| 高度 | 0.257 稳定 |
| 最大倾角 | 0.007 rad |
| 摔倒 | 否 |

**必须说清**：站住是 PD 撑的。大脑的力度只当 ±0.02 rad 的偏置，等于"接上了、不捣乱"，
不是"大脑在控制站姿"。

**力度 → 姿态的耦合**（直接喂示范力度，不经大脑）：

| 偏置 rad | 看左边 | 看中间 | 看右边 |
|---:|---:|---:|---:|
| 0.12 | roll −0.063 | −0.037 | −0.010 |
| 0.25 | roll −0.119 | −0.077 | −0.043 |
| 0.40 | +0.379（开始失稳） | −0.121 | −0.150 |

结论：**三档力度能让狗按方向倾、不摔**（单调）。所以"大脑→身体"这条路是通的，
缺的只是"大脑从画面算出该给哪三档"。

## 还差的一步

`experiments/p3_cue_body.py` 想把"色块位置 → 12 块肌肉力度"编译成连接（log-odds），
但编译出来的力度细胞**输出恒为 0**：分数是"数百维状态向量点乘权重"，量级到几十，
而力度细胞的驱动还混着运动中继那一份，两者尺度没对齐，门槛落在错误的位置。

修法（下一轮）：把权重按"典型分数"归一，并且只让编译出的连接驱动力度细胞
（把运动中继那一份权重清零），这样"抄来的策略"才是唯一驱动，尺度可控。
