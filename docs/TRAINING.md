## 1. 三条训练路线（不是互斥，是接力的）

### A. 本能 / 抄动作（不需要学习）

**做法**：把动作录成"每一拍的肌肉组合"，在皮层里展开成一条链：
第 0 拍 → 第 1 拍 → … → 最后一拍 → 第 0 拍（循环）。只要点亮头一拍，这串动作
就自己在皮层里一拍一拍走下去。

**老库的实测**：12 拍的"中走"从头点到尾转了 28 拍不乱，每一拍解出来的肌肉发力和
抄下来的完全对上；26 个动作里 10 个姿势 + 3 个慢动作全部成功，走路类一半成功一半摔。

**两个必须遵守的细节**（这两条对我们直接有用）：
1. **保持姿势必须是 2 拍自环**：只点一下保持不住——神经元不会一直亮着。
2. **慢动作放完必须接上"站姿"那一圈**，否则动作一停肌肉就松、狗塌下去。

⚠ 我的判断："28 拍不乱"证明的是**循环链能自走**，不是"学会了动作"；
它依赖手写的链，不依赖学习。可以当 v0 的运动原语，不能当学习成果。

### B. 顺序赫布长连接（本库 P1，进行中）

**做法**：喂有先后结构的经历，让"上一拍亮 A、这一拍亮 B"长出 A→B 的有向边
（凹增长、top-k、整体降权、扇出归一）。

**我们的实测**（见 `P1_LOG.md`）：1200 拍长出约 9 千条边；在"left→mid→right→mid"
序列上，联想召回 **0.401→0.500（+0.099）**，三个网络种子的提升 +0.030/+0.042/+0.099，
对照组 0.000/−0.025/−0.022。**方向成立，幅度还小。**

**两个关键前提**（是这一轮试出来的，不是老库里的）：
- 前额叶必须有**动态抑制**（每拍只留最强 2%），否则码太密，A 的单元 92% 本来就在 B 里，
  根本测不出联想；
- 必须**慢自适应**（`pfc_adapt≈0.01`）。快了（0.05）会把 A 的单元在 B 出现前就"习惯掉"，
  召回反而变成负数（实测 −0.014）。

### C. 蒸馏"状态 → 动作"（动态步态必须走这条）

**老库最重要的负结果**（14.7）：把训练好的策略的关节角序列原样放，**一半走两步就摔**。
原因不是抄错，而是：走路不是一串姿势，是**每 20 ms 根据身体状态做一次修正**；
把闭环策略压成开环轨迹，等于把反馈扔了。

**正确做法**：新增本体感觉/耳石区（关节角、角速度、机身倾斜），把训练好模型里
"状态 → 动作"那一层**抄成连接**接到运动区。老库把这一步列为"下一步要你定"。

**我的判断**：这是对的，而且它解释了为什么 P2（运动学习）不能只做"动作链"。
对我们的直接含义：**运动区最终要有两条输入**——前额叶下来的"意图"（离散、慢），
和本体/平衡上来的"修正"（连续、快）。两条都走神经元，不写 if-else。

## 2. 模型融合（fusion）

老库的用法是"把单独训练好的模块接起来"，不是把两个大模型平均。要点：

| 契约 | 要求 | 为什么 |
|---|---|---|
| 同一套编码 | 每个模块的输入都是"每通道温度计正反、每档恰好亮一个" | 编码不一致，接上去等于噪声 |
| 同一个时钟 | 一拍 20 ms；模块内部可以有小步，但对外只有一拍 | 时间基准不一致，先后顺序就乱了 |
| 稳定 ID | 融合只加编号、不移位；删只改 alive | 否则已经长出来的连接会指错人 |
| 接口在皮层 | 融合发生在**神经元/边**这一层，不在文件/函数层 | 只有这样"融合"才是真的接上，而不是两个程序互相调用 |
| 可切断 | 融合后必须能单独切断新接的通路做对照 | 证明行为来自新通路，而不是碰巧 |

⚠ 我的判断：老库说"旧版有融合实验，当前完整宠物尚未验证融合"——这句话要当真。
**没有切断对照的融合，不能算验证过。**

## 3. 测试协议（按证据强度从弱到强）

1. **行为测试**：闭环跑一段，看指标（走了多远、站了多久）。弱——可能靠反射碰巧。
2. **干预测试**：切断一条通路（group 30 / 回程 / 前额叶），行为应退化到对应水平。
   强——证明因果。我们的 `check_behavior` 只做了"前额叶要有活动"，还没做切断对照。
3. **反事实测试**：同一帧、不同前序，码应该不同（P1 的 `context_test`）；
   但注意方向——学到的联想会让码**更不依赖前序**（补全/去噪），距离变小不一定是坏事。
4. **反例测试**：给系统一个它"应该分不清"的输入，看它是否真的分不清
   （老库的颜色漂移测试就是这个思路）。

⚠ 老库 19.9.6 的教训：**测试设计对，但被测的网络没有那个能力时，测出来的是网络的问题，
不是机制的问题。** 所以每个测试都要先问"这个网络理论上能不能做到"。
（他们的颜色测试失败，最后归因到"视觉网分不清颜色"，不是"赫布不工作"。）

## 4. 落到 ANA 的阶段安排

| 阶段 | 训练 | 测试 |
|---|---|---|
| P1（当前） | 顺序赫布 + 动态抑制 + 慢自适应 | 反事实（同帧不同前序）+ 召回（cue A → B 单元） |
| P2 | 蒸馏"状态→动作"：用示范/已训练策略生成 (本体, 动作) 对，把映射长成连接 | 干预：切断前额叶→运动区，狗应站不住；切断本体→运动区，狗应走不稳 |
| P3（Go2） | 先接本能动作链（Pose 自环 + 慢动作接站姿），再接蒸馏层 | 行为 + 干预 + 跌倒恢复 |

**P2 的第一条实验**（不需要狗）：在虚拟身体上，用"脚本策略"生成 (proprio, forces) 对，
训练"本体 → 运动区"的连接，看能否比随机接线更稳。这一条能先验证"蒸馏成连接"这条路。
