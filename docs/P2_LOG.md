# P2 实验日志：把"状态 → 动作"变成连接

## 2026-10-21 第一次尝试：用共激活蒸馏（失败，但有信息）

**任务**：示范策略把平衡状态映射成 12 块肌肉的力度（右侧倾→左腿加力，前倾→后腿加力）。
**做法**：喂状态 → 让平衡区神经元活跃；同时用示范动作"顶着"运动单元（teacher forcing）；
把"活跃的状态单元 → 该亮的运动单元"用监督式共激活长成连接（group 41）。
**测试**：撤掉示范，只喂状态，看产出的力度和示范差多远。

| 尝试 | 结果 |
|---|---|
| 源 = 前额叶 | 前额叶 top-k 2% 被视觉/背景占满，平衡挤不进去，**源头是空的**（活跃源 0） |
| 源 = 平衡 L1–L5 | 长出 4,844 条边，但测试时只有 18 个源活跃，驱动 0.18 < 阈值，**力度全 0** |
| 加大扇出（topk 16 → 64） | 单边权重被摊薄（wp 0.054 → 0.013），**还是 0** |
| 加传播增益 prop_gain=5 | 力度非 0 了，但**几乎不随状态变**（0.15–0.2 一条直线） |
| 源 = 平衡 L5（更稀疏） | 只剩 176 条边，驱动更弱，**全 0** |

## 判断

1. **不是学习规则错**：边确实长出来了，权重也到了 0.78；是**读出结构不对**。
   运动区是"数亮几个中继单元"的分档结构，需要**很多单元同时被驱动**；
   而共激活蒸馏出来的连接是"少源 → 宽目标"，驱动摊薄后谁也过不了线。
2. **共激活不是监督**：它只记录"一起亮过"，不记录"差多少"。示范是连续的（0..1 力度），
   共激活只能学"亮/不亮"，学不出刻度。
3. **老库的做法其实不是"学"，是"抄"**：把训练好模型的"状态→动作"那一层**直接抄成连接**，
   权重来自策略网络，不来自共激活。我这次做的是更难的那件事，结论是：
   在"数个数"的读出结构上，共激活学不出连续映射。

## 两条备选路（下一轮选一条）

**甲、抄（compile）**：把示范策略在状态网格上跑一遍，得到查表；用
`log P(力度档 | 状态单元)` 直接算权重写进连接。一次性、确定、可检验：
在训练用过的状态上必须 100% 复现示范；在新状态上看插值。

**乙、改读出**：运动区加一条"状态 → 力度档"的直连（group 42），
每个力度档细胞自己收状态线、自己的门槛。这样连续量可以直接长，不再依赖"数中继"。

我倾向**先做甲**：它对应老库"抄一层"的原话，能立刻验证"蒸馏成连接"这条路通不通；
乙是改结构，应该等甲证明了接口再动。
