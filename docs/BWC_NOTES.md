# 读 born-wired-cortex 的笔记（对照 ANA）

## 一、它的整体

感觉 → 前处理网络（固定权重、稀疏、环形邻域）→ **前额叶**（视觉+听觉+运动命令三路汇入）
→ 前额叶把输出**镜像返回**到感觉区（"想"的时候重新点亮感觉）→ 运动区（反向赫布网络）
→ 肌肉 → 身体 → 新的感觉。

记忆有三块：视觉记忆、听觉记忆、运动记忆，都是"**特征 ↔ 时间**"的双向连接，
靠一个共享的**海马时间环**（172.8 万个时间神经元、每个 0.05 秒、两格一拍、24 小时一圈）来定序。

## 二、和 ANA 的根本不同（不是错，是路线不同）

| 项 | bwc | ANA（你的选择） |
|---|---|---|
| 记忆挂在哪 | 特征 **↔ 时间**（海马时间环） | 前额叶神经元**之间**，没有时间索引 |
| 时间 | 有全局时间环，一个时刻只有一个位置亮 | 没有专门的时间区 |
| 前额叶内部 | 有联想区（赫布 + 动态抑制） | v0 是 0 条，靠训练长 |
| 前额叶输入 | 三路**扩散 + 汇合细胞**（25%，长程，门槛更高） | 1:1 专用线（你要的"一个字一个单元"） |
| 运动 | 200 块肌肉、反向赫布、一次学会 | 12 关节、力度档、出生接线 + 可塑 |

**判断**：这两条路线都能自洽。bwc 的"时间环"解决的是"哪一刻发生了什么"；
你的"前额叶之间长连接"解决的是"哪些东西互相关联"。**我们不做时间环**，因为你说过
记忆是前额叶神经元之间的连接，不是外挂的时间索引。

## 三、值得学过来的三样（具体、低风险）

1. **动态整体抑制按"典型思维大小"自适应**：它跟踪"平时想多大一片"，把活动压在
   0.5–1.3 倍之间；我们用的是"固定留 0.5%"的 top-k。前者更稳（输入强弱变化时不会
   忽多忽少），可以做成 `pfc_topk` 的自适应版本。
2. **运动"反向赫布 + 一次学会 + 有门控的生长"**：
   - 一次学会（`一次学会=True`：突触直接饱和到 1，学过就不会忘）；
   - 生长有门控：**先试着回忆，回忆已经对了就不再长新边**（防重复动作把记忆灌满）；
   - 出生镜像底版：没学过的命令也能给出大致方向。
   这正好补我们 P2"编译出来的映射脆弱"的问题——用它的三条，比我们现在的 log-odds 编译稳。
3. **汇合细胞**（多路输入 + 提高门槛才过线）：这是"几个感觉对上了才算一个念头"的机制。
   我们的 1:1 前额叶没有这个；可以做成**可选的一小撮**（比如 25%），不影响 1:1 主线。

## 四、它自己承认的问题（我们别重复）

- **无锚自由联想会漂**（像走神）；沿着真实闭环回放不漂。
- **时间记忆会一直长**（1 万拍后 37.5 万条），靠衰减维持实时。
- 闭环仿真只有**二维推车身体**，不是四足。
- 论文阶段"教它听见声音就走"仍会摔（两个动作抢一个身体）。

## 五、和 ANA 现状的对照结论

- 我们的"感觉→链→额叶→运动→身体"与它的主干一致；差异在**记忆挂在哪**和**前额叶怎么汇**。
- 它没有"每层精确 top-k、恒定活跃数"这一条（它用阈值 + 逐层增益 α 稳住数量）；
  这一条来自 local3d 和你的"十盏灯"，我们要保留。
- 它的"固定 vs 可塑"划分（前处理/镜像线固定，记忆/联想/运动反向可塑）**和我们的
  group 划分一致**，可以直接对照：我们只有 group 40/41 可塑，其余全冻结。
