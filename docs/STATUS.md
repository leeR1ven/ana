## 二、已经做到的三件事

### 1. 完整框架（v0）

感觉（视觉 32×32×3、听觉 32×4、触觉 20、本体 36、平衡 10）
→ 每区一条链（L1 ON/OFF + L2–L5，固定权重、就近局部、每层精确 top-k）
→ 每层 1:1 专用线 + 两级中继 → 前额叶（每层一组，像一个个"字"）
→ 回程（抑制神经元规则决定"只有最强的那条能过"）
→ 运动区（12 块肌肉 × 10 档力度 + 抑制/去抑制门控）。

**前额叶内部 0 条连接**——按你的要求，记忆必须长出来，不能焊死。

### 2. 狗接上了

`agi/body_go2.py` + `experiments/p3_go2.py`。物理 500 Hz、大脑 50 Hz。
大脑在跑的情况下狗站得住（0.257 m，倾角 0.007 rad），整拍 9.9 ms。

### 3. 大脑能驱动狗（但靠"抄"）

把"色块在左 → 左腿用力"这种示范编译成连接（`experiments/p3_cue_body.py`），
只喂画面：左 −0.070、中 −0.031、右 +0.006（单调右移），关掉这条连接两个画面完全一样。
**这是"大脑按看到的东西驱动身体"的第一个可复现证据，但连接是抄的，不是学的。**

## 三、还没做到的（不要当成能力）

1. **联想还弱且不稳**：点 A 的神经元，B 的专属单元命中 8 个（乱点 1.6），
   但乱点在 0–8 之间跳——网络处在"快要整体兴奋"的边缘。
2. **没有任何"学会"的运动**：狗的站立是 PD 撑的；倾斜是抄的示范。
3. **视觉是合成图**，不是相机；听觉/触觉在狗身上还是常数。
4. **没接真机**。

---

## 四、这一路踩过的坑（都写进代码注释了）

1. **参数位置写错**（把"百分比"当成绝对值传进去）——所有层门槛低 8 倍，L1 全饱和。
   一个错误让后面几轮实验全部作废。
2. **预热拍数不够**：深链要 15–18 拍才传到前额叶，6 拍就下结论会把 93% 单元误判成"常灭"。
3. **测试不公平**：拿"87% 像素相同"的两张图当"完全不同的图"，测出来的是测试的错。
4. **信号逐层衰减**：用"名义活跃比例"归一，活动每层掉一半；改成按实测驱动定带宽才对。
5. **学习采样太稀**：500 个单元两两 25 万对，每拍抽 2048 对，真转移一万次也抽不到几次；
   改成"换画面时全配对学"。
6. **回程不是常开回路**：它是"只有最强信号过、随思考焦点移动"，由抑制神经元实现，
   不能另加闸门模块（这是我理解错、被你纠正的地方）。

## 六、下一步（按重要性）

1. **把联想调稳**：整体抑制要能随训练自适应，让"乱点"接近 0 且不漂移。
2. **让狗的动作是学的**：用同一条编译管线，但示范换成"扰动后自己恢复"的数据，
   接进 Go2 的平衡环（这一步才能真正说"大脑在控制站姿"）。
3. **换真传感器**：相机 + IMU 接进同一套编码，验证"同一个画面 → 同一批神经元"在真实输入上成立。
