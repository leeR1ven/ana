# 这个架构其实很简单（把脚手架剥掉之后）

## 内核：七条

1. **输入变成成对的神经元**：一个数值 → 一串"亮/灭"对，每对恰好亮一个（温度计）。
2. **每一层只看上一层附近几个**：权重出生时随机定好，**以后不改**；加权和过阈值就亮。
3. **每一层都往额叶送一条专线**：额叶是终点，不往回拐。
4. **额叶顺着返回线送回感觉区**：这就是"在心里看见/听见"。
5. **额叶神经元之间按"先亮 → 后亮"长连接**：这就是记忆；用得越多越难改。
6. **运动区：每块肌肉一组神经元，亮几个 = 多大力**；它只是"输入层"，动作是别处点亮它。
7. **区与区之间也有直连**：多数出生就有、难改；一起反复亮的会慢慢固化。

就这些。没有注意力、没有梯度、没有语言规则、没有外挂记忆库。

## 附三：别再犯这些错（本次开发中真踩过的）

1. **跨稀疏度比 Jaccard**：69 个单元的码和 671 个单元的码不可比。要看"交集/自身 vs 随机期望"。
2. **把分位当门槛**：给每级规定活跃比例 = top-k 换马甲，违背"不要名额"。
3. **一次性设所有层的门槛**：上层会因下层没输出而饿死。必须浅→深逐级设。
4. **用全局 θ·mass 卡所有级**：各级驱动的量级差很多，同一个系数不可能都合适。
5. **把"活跃少"当缺陷**：清醒皮层本来只有 1~5% 在放电，稀疏是目标不是 bug。
6. **硬冻结长期记忆**：应该是"难改但永远可改"（留 1% 可塑性），冻结会留下改不掉的错误。
7. **只按权重总量判"谁强"**：驱动接近时门槛会全过或全不过；对比度/阈值要一起看。
8. **教学时提示和训练用不同集合**：装了 660 个源的边，提示却点 3,681 个 → 力度推满。
   装了哪批、就用哪批去点。
9. **边的方向写反**：`add_edges(源, 目标)`，反了会"怎么调都没反应"，极费时间。
10. **多线程求和不固定**：`torch.set_num_threads(1)`，否则同图同码会间歇失败。

## 附五：简化项——"抑制细胞"其实就是负权重的普通神经元（待做）

引擎里的"抑制细胞"只是标记 `is_inh`，计算时把它的出边乘 −1：

```python
sgn = np.where(self.is_inh[src], -1.0, 1.0)
```

所以它**等价于普通神经元 + 负权重边**，不需要单独的细胞类型。彻底简化要做三件事：

1. 写入时就把符号乘进权重（`w = w * sgn`），引擎计算不再乘 `sgn`；
2. `check()` 里"权重必须为正"的断言改成"允许负权，但校验 I/D 的符号关系"；
3. 构建里 `inh=True` 的写法可以全部去掉，改成"连负权边"。

**试过一次、当场回退**：只改第 1 步会让 2 个测试和 3 条自检失败（它们假设权重为正），
所以这三步必须一起改。回退后仓库保持全绿。

**概念保留**：架构里仍然有"抑制神经元"这个说法，因为要说清"它为什么存在"——
它的目的就是**压制别的神经元**（例如"很少一起出现 → 互相压住"）。
但它不是另一种细胞：它就是一个**输出权重为负的普通神经元**。

**实现已简化**（2026-10-22）：符号在写边时就乘进权重，
引擎计算不再单独乘 `sgn`；自检、I/D 关系、文档里的概念都保留。
改完复查：17/17 测试、0 issues、地基符合、狗 0.269、规则表 0.50。

### 为什么"抑制神经元"这个概念必须保留

机器的"不做某个动作"有两种完全不同的原因：

1. **没有信号**：负责那个动作的神经元没被点亮（被动地没发生）；
2. **被主动压住**：那个神经元本来想亮，但被抑制神经元按住了（主动地不许发生）。

没有第 2 个概念，别人会以为机器"没信号所以不动"，而实际上很多行为是**被压着**
才不动的——比如：
- 站姿反射想出力，但前额叶在说"现在别动"；
- 两个动作抢一个身体，弱的那个不是"没有"，是被强的压住了；
- 罕见但正确的连接不是"不存在"，是被常见连接压着，需要一次强共现才翻过来。

所以"抑制神经元"不是实现细节，是**解释行为所必需的概念**。
实现上它只是负权重的普通神经元（见附五），但说的时候必须当成一种角色来讲。

### 不要再造一个"遗忘"机制（2026-10-22，用户指出）

`PlasticRule` 里本来就有整体降权（`decay`/`decay_every`），所有边一起慢慢变弱。
我又在 `Consolidator` 里单独写了一套"长期边衰减"——**重复了**，已删除。

规律：**遗忘是全脑统一的，不需要按边组各搞一套**。要"常用的保持住"，靠的是
"反复出现时再加强"（凹增长），而不是给常用边单独一个更慢的衰减。

### 降权按神经元类别分档（2026-10-22，用户建议）

整体降权仍然只有一套（`PlasticRule._decay`），但**不同层深的神经元掉得不一样**：

| 层深 | 相对系数 | 含义 |
|---|---:|---|
| L1 | 0.90 | 最浅，掉得最快 |
| L2 | 0.93 | |
| L3 | 0.96 | |
| L4 | 0.98 | |
| L5 | 0.995 | 深层特征，稳 |
| PFC | 0.999 | 近乎不掉 |

实现只按 `engine.depth` 查一个 6 项的表，不给每个神经元存额外状态——几乎不花性能。
这符合"简单分几类、不同类别降权程度不同"的要求，也没有新增第二套遗忘机制。
