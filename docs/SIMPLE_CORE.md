# 这个架构其实很简单（把脚手架剥掉之后）

## 内核：七条

1. **输入变成成对的神经元**：一个数值 → 一串"亮/灭"对，每对恰好亮一个（温度计）。
2. **每一层只看上一层附近几个**：权重出生时随机定好，**以后不改**；加权和过阈值就亮。
3. **每一层都往额叶送一条专线**：额叶是终点，不往回拐。
4. **额叶顺着返回线送回感觉区**：这就是"在心里看见/听见"。
5. **额叶神经元之间按"先亮 → 后亮"长连接**：这就是记忆；用得越多越难改。
6. **运动区：每块肌肉一组神经元，亮几个 = 多大力**；它只是"输入层"，动作是别处点亮它。
7. **区与区之间也有直连**：多数出生就有、难改；一起反复亮的会慢慢固化。

就这些。没有注意力、没有梯度、没有语言规则、没有外挂记忆库。

## 复杂度是我加的（可以删）

| 我加的东西 | 为什么加 | 现在还需要吗 |
|---|---|---|
| top-k 固定名额 | 为了让"每层亮几个恒定" | **不再需要**：权重相对阈值 θ·(\|b\|+Σ\|w\|) 更好（近似 0.94 / 异图 0.18） |
| PMI 闸门 | 为了压"万金油连接" | 默认关了，现象照样成立 → 可删 |
| 枢纽抑制 | 同上 | 默认关了 → 可删 |
| 互抑制（负边） | 想实现"抑制伙伴" | 无效/有害 → 可删 |
| `gain_div` 除法增益 | 学字网络的刹车 | 在 top-k 下无效 → 可删 |
| 出生偏置 `bias_scale` | 学 local3d | 破坏同图同码 → 可删 |
| 固化计数 `use_ref/plast_min` | 想实现"用多了难改" | 有验证，保留（这是内核第 5 条） |
| 稳定码学习、新颖目标 | 为了能测出联想 | 是"怎么喂数据"的问题，不是架构 → 可简化 |
| 一堆实验脚本（p1~p14） | 验证用 | 留着当证据，不影响内核 |

## 一句话

**内核是"成对神经元 + 局部固定连接 + 阈值 + 专线汇到额叶 + 返回 + 前后长连接 + 力度分档"**；
其余都是我为了"让它表现成某个样子"打的补丁。补丁越多，越容易把简单的东西搞复杂——
这也是为什么最近几轮一直在往回删。

## 附：阈值模式的推荐配置（已实测）

```python
build_spec("full", threshold_theta=0.7, pfc_fan_in=4, pfc_ratio=0.25)
```

| 指标 | 结果 |
|---|---|
| 同图两次 | 完全一致 |
| 近似图 | 0.93 |
| 完全不同的图 | 0.07 |
| 名额（top-k） | **完全不用** |

对比默认的 top-k（0.91 / 0.22）。代价：额叶每个单元读 4 根中继线，而不是严格 1 根。
默认没切过去，是因为严格 1:1 时阈值只能切出 69 个单元、近似掉到 0.65；
这条取舍（一条专线 vs 无名额稀疏）留在 `docs/AUDIT_CODE.md` 第四十五节，等你定。
