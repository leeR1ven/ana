# P1·第二轮：PMI 闸门与"只学刚变化的"（2026-10-22）

## 改了两处（都是按库里原文补的）

1. **特异性闸门（PMI）**：`wp *= sigmoid(steep·(PMI − offset))`，下限 0.12，
   共现计数按 500 拍滑动衰减。单元测试：同样共现 10 次，稀有搭档的闸门 > 万金油搭档。
2. **只学"刚变化的"**（链式库 `plastic2` 的原话）：上一拍亮、这一拍灭 ↔ 这一拍刚亮。
   改之前我把"整批活跃单元"两两配对，导致 A 的边 56% 指回 A 自己；改之后降到 38%，
   并且首次出现方向性：A→B 145 条、A→C 104 条（B 是被 A 跟着的那个）。

## 但功能上仍然推不动

| 测法 | 结果 |
|---|---|
| 纯点 A（不喂画面），看 B 的专属单元 | B 专属命中 0–18，**C 专属命中 0–20**（无偏向） |
| B 专属单元收到的驱动 | 0.03 / 个，门槛 0.14（差 4–5 倍） |
| 提高传播增益 20×、线性归一、关 PMI | 仍然 0 |
| 模糊的 B（亮度 25%）+ 先点 A 再补全 | 恢复 0.53 → 0.51（**−0.02**，没有补全） |
| 同样的模糊 B 直接看 | 0.53（本来就恢复得不错，没有提升空间） |

## 判断

- 学到的连接**结构上在**，但**每个目标只分到 1–2 条边**（A 的 145 条边摊到几十个 B 单元），
  单条边的传播权重（0.02–0.15）远低于 PFC 的门槛（0.14）；
- 前额叶现在被那条 1:1 感觉线**喂到饱和**（驱动 0.85 >> 门槛 0.14），联想 0.03 只占 3%，
  改不动码。这不是"学错了"，是**读数放大倍数不够 / 联想扇入太稀**。

## 下一步（要做对的地方）

1. **让 PFC 处于"半饱和"**：把感觉线单独驱动到 act≈0.5（门槛 ~0.6×入边和），
   联想才有话语权；现在还差得远。
2. **提高联想扇入**：每个 PFC 单元收到的联想边从 1–2 条提到 10–20 条
   （要么 topk_out 加大，要么 PFC 单元数减少）。
3. 补全测法要更严格：用"B 被遮挡/降采样"而不是整体压暗（压暗只是降对比度，识别本来就稳）。

## 追加：按"半饱和 + 大扇出"再试（同日）

思路：让前额叶被感觉线单独驱动到 act≈0.5（门槛 0.55×入边和），给联想留出空间。

| 设置 | 结果 |
|---|---|
| 半饱和（thr 0.55）+ 扇出 8 | 只看 B：B 均值 0.572；看 B 再带 A：0.604（+0.03），但 **B 专属单元 0.471 → 0.471**（没有特异性） |
| 半饱和 + 扇出 32 | 联想边从 9,600 掉到 2,762（前额叶更稀疏 → 参与学习的对更少），仍然推不动 |
| 把前额叶缩到 1/5（pfc_ratio 0.2）提高扇入 | 建网直接崩：回程接线长度对不上——**1:1 结构假设前额叶与层同尺寸** |

## 结论（本轮定论）

在现在的 1:1 前额叶结构下：
- 每个前额叶单元的联想入边只有约 **3 条**（9k 条边 / 3k 个目标），单条传播权重 ~0.02，
  合计 ~0.06，而门槛 0.14（半饱和时 0.52）——差 2–8 倍；
- 想提高扇入，要么缩小前额叶（和 1:1 冲突），要么给每个目标补更多边（和 top-k 稀疏冲突）。

**这是一个结构性约束，不是调参能解决的。** 下一轮要么改 1:1 的建网（允许前额叶比层小、
回程按比例接），要么接受"联想只能调制、不能单独点亮"这个事实，把测试改成调制量的统计检验。
