# 代码级核对（char-neuron 的 brain.py）

> 只记"代码里实际写的"，不引用 README。参数取自 `_orig/char-neuron-network-main/code/brain.py`。

## 一、它实际用的参数

| 项 | 值 | 含义 |
|---|---|---|
| `top_k` | 32 | 每个单元最多保留 32 条出边 |
| `w_max` | 1.0 | 连接强度上限（另有一个 1e6 的数值安全上限） |
| `learn_eta` | 0.02 | 在线学习步长（一次思考只走一小步） |
| `decay` | 0.45 | 每步激活衰减（持续激活被当作正常现象） |
| `gain_control` | 0.01 | **除法式增益**：激活越多，整体越难再推高 |
| `theta_lr` | 0.5 | 全局阈值的收敛速度（不是 ±5%，是直接朝目标追） |
| `act_eps` | 0.35 | 判定"亮了"的阈值 |
| 权重生长 | `growth_curve(共现次数)` | 凹形：次数越多涨得越慢，不是每次加固定量 |

## 二、和我们的做法对照

| 项 | 它 | 我们 | 判断 |
|---|---|---|---|
| 选多少单元活跃 | 全局阈值 θ 追目标数（θ_lr 0.5） | top-k 固定比例 + 增益只许 ±5% | 它的更"软"，我们的更"硬"；**你的"十盏灯"要求硬恒定**，保留我们的 |
| 防跑飞 | 除法式增益 `drive/(1+γΣa)` | 没有 | **值得补**：规模一上去，这是最直接的刹车 |
| 出边数 | 32 | 8–32（实验里用 32） | 一致 |
| 权重生长 | 按共现次数的凹曲线 | 每次共现加 `η(1−w/wmax)` | 数学等价（都是凹），一致 |
| 激活衰减 | 0.45/步 | τ=0.025、dt=0.01 | 量级不同，效果类似 |

**结论**：核心机制我们没写错；差的是"除法式增益"这一条，可以作为可选开关补上。

## 三、你补充的两条结构，现在**确实没有**

1. **区与区之间的直连**：现在五个区各自成链，只在额叶汇合；没有"视觉↔听觉"这种直连。
   你说过这类连接大多**很难改**，反复接触才慢慢固化成长期记忆。
2. **"常用变难改"的固化**：现在可塑连接只有一条"整体降权"，没有"用得越多越难改"。

### 打算怎么做（下一轮动，先写清楚再动手）

- **区与区直连**：在相邻区的 L5 之间加一小束固定连接（比如视觉→听觉、听觉→视觉各 64 条，
  权重固定、不参与学习），走一个新的边组，自检里加一条"这类边必须不可塑"。
- **固化**：给每条可塑边加一个"资历"计数。用得越多，它的**可塑系数**越低
  （η 乘一个衰减因子），低到一定程度就标成"长期记忆"、不再被改；同时它仍参与传播。
  这样"反复接触 → 变成长记忆"是长出来的，不是手写的。
- 两条都要过：地基体检、自检 0 问题、16 项测试、20 ms 预算、狗能站。

## 四、下一步顺序

1. 先把除法式增益做成可选（`pfc_gain_div`），验证不破坏地基；
2. 再加区与区直连（固定）；
3. 最后加"用得多就难改"（固化），并用一个三阶段实验验证：

## 五、第 1、2 步的结果（2026-10-22）

已实现（`drive ← drive / (1 + γ·Σa)`，只对前额叶）。实测：

| γ | 前额叶活跃 | 近似图 | 异图 |
|---:|---:|---:|---:|
| 0 | 671 | 0.91 | 0.22 |
| 0.01 | 671 | 0.91 | 0.22 |
| 0.05 | 671 | 0.91 | 0.22 |

**完全没有影响**。原因：我们的前额叶是 top-k 竞争 + 饱和响应，整体乘一个系数不改变排名。
它只在"分级响应"的网里起作用（字神经元网络就是那样）。**保留开关、默认关闭**，理由记在这。

### 第 2 步：区与区之间的直连（`region_links`）

### 第 3 步（未做）：常用连接固化成长期记忆

## 六、第 3 步：用得多就变难改（固化）

每条可塑边带一个"用过几次"的计数：

- 可塑性随使用下降：`系数 = use_ref / (use_ref + 用过次数)`（下限 0.02）；
- 超过 `freeze_at` 就**冻结**：权重不再改变，但仍参与传播（长期记忆）。

单元测试（同一对神经元反复加强 40 次）：

| | 最终权重 | 是否冻结 | 用过次数 |
|---|---:|---|---:|
| 固化开 | **0.62** | 是 | 40 |
| 固化关 | 1.00 | 否 | — |

所以"反复接触 → 变难改 → 冻结"是按规则长出来的，不是手写的。
（顺带补回了向量化重写时丢掉的 `reinforce` 接口。）

## 七、第 3 步修订（按用户 2026-10-22 的纠正）

**长期记忆是"难改"，不是"不能改"。** 硬冻结会留下无法纠正的错误，所以改成：

- 可塑性 = 下限 0.01 + (1−下限) × `use_ref/(use_ref+用过次数)`；
- 用得越多，每次改动越小，但**永远留 1% 的可改性**；`long_term_at` 只是打标记，不禁止修改。

单元测试（同一对反复加强）：

| | 40 次后权重 | 再多 10 次 |
|---|---:|---:|
| 不固化 | 1.000 | — |
| 固化 | 0.772 | 0.793（仍在变） |

### 真实网络里的发现（p6_consolidate.py）

- 第一段 300 拍：155,968 条边，**平均只被用过 1.0 次**，长期记忆 0 条；
- 原因：新颖目标 + top-32 剪枝，让每次转移都在"新边"上打转，老边很少被再次用到。

**结论**：固化规则本身没问题，但现在的学习方式不爱复用老边，所以"反复接触→变长期"
在真实网络里还没发生。下一轮要改的是"复用优先"（新边只在确实没有可用老边时才长），
这正好也是 born-wired-cortex 那条"先试回忆、回忆对了就不再长新边"。

## 八、第 4 步结果（复用优先 + 难改的定量验证，2026-10-22）

加了"复用优先"（源头出边够 4 条就不再长新边，只加强已有的）后，用 800+800 拍跑：

| | 条数 | 总变化 | **每次被用改** |
|---|---:|---:|---:|
| 老边（用过 ≥8 次） | 878 | 0.049 | **0.0049** |
| 新边（用过 ≤1 次） | 2,275 | 0.024 | **0.0181** |

**老边每次被用到时，改的量只有新边的 0.27 倍**——"难改，但不是不能改"在真实网络里成立。

注意：不能看"总变化"（老边总变化更大，因为它们被反复用到），要看"每次被用改多少"。
这是这一轮差点被数字骗到的地方，记下来。

## 九、融合：一次学会（P9，2026-10-22）

按 born-wired-cortex 的"反向赫布 + 一次学会"：

1. 看画面 A，记下亮的 694 个前额叶单元；
2. **一次**把它们连到 12 块肌肉的前 5 档力度上（41,640 条边，权重直接给满）；
3. 画面全黑、只点 A → 力度 0.55；狗从趴着 0.100 站到 0.255，不摔；
4. 中间看别的画面 200 拍，再回来点 A → 力度仍是 0.550。

**学过不忘**。这就是"把示范动作搬进架构"的具体做法：不需要反复训练，
一次写入、直接饱和，之后别的活动冲不掉。

局限：现在是"画面→站"一条固定映射，还没做"多动作累积"（学第二个动作不冲掉第一个）；
下一轮补。

## 十、多动作累积 + 门控生长（P10，2026-10-22）

| 步骤 | 结果 |
|---|---|
| 教 A（站，5 档，只用 A 独有的 4,490 个单元） | 26,940 条边 → 点 A 力度 **0.50** |
| 教 B（撑，7 档，只用 B 独有的单元） | 37,968 条边 → 点 B 力度 **0.70** |
| 回头再点 A | **0.50，没被冲掉** |
| 再教一次 A（门控） | 先试回忆已能给出 0.50 → **新增 0 条边** |

**关键**：教的时候只用"这个场面独有"的单元，否则共享单元会同时驱动两套边，
两个动作互相串（第一次试就串了：教完 B 再点 A，力度变成 0.72）。
这和用户说的"概念范围"是一回事——动作要挂在**区分性**的单元上，不是挂在整个场景上。

这样就同时满足："教新动作不忘旧的" + "已经会的就不重复写边"。

## 十一、local3d 的权重细节（逐行核对 model.py，2026-10-22）

它每个神经元固定 4 条输入：

| 输入 | 权重 | 说明 |
|---|---|---|
| 自身位置（同坐标） | **1.0** | 第一条永远是"自己" |
| 3 个随机邻居（dx,dy∈±1，dz∈±2） | (0.5~1.0)×**alpha**，alpha=0.01 | 即 0.005~0.01 |
| 固定随机偏置 | 0~0.5 | 直接加在加权和上 |
| 读出 | 每层精确 top-k | 选中=1，其余=0（**二值**，没有分级） |

对照我们：

| 项 | 它 | 我们 | 差异的影响 |
|---|---|---|---|
| 自身拷贝权重 | 1.0（邻居的 100~200 倍） | 1.0（邻居的 5~20 倍） | 我们的层"更像混合"，它更"保形"；这可能是它近似图 0.989、我们 0.91 的原因之一 |
| 偏置 | 有（0~0.5） | **没有** | 它每个神经元的"易兴奋程度"不同，我们靠并列优先级代替 |
| 阅读方式 | 二值 top-k | 分级 act + top-k | 我们的码带强度信息，它的更干净 |

**判断**：偏置这一条值得补（成本低、符合原意），但要用"每个神经元固定的随机偏置"，
不能变成可调参数（否则又是给现象加机制）。自身拷贝的权重比例是两种设计取向，
暂不照搬——我们要"加工"，不只是"保形"。

**待办**：给层神经元加固定随机偏置（`bias_scale`，默认 0 以便对照），验证地基指标。

## 十二、补 local3d 偏置的实测（2026-10-22）

实现：每个层神经元出生时给一个固定随机偏置（0~bias_scale），加在驱动上。

| bias_scale | 活跃 | 同图两次完全一致 | 近似图 | 异图 |
|---:|---:|---|---:|---:|
| 0（默认） | 671 | **是** | 0.91 | 0.22 |
| 0.2 | 666 | **否** | 0.90 | 0.20 |
| 0.5 | 666 | **否** | 0.90 | 0.20 |

**加偏置会破坏"同一输入→同一批神经元"**（和第 3 条门槛公式那次一样：更多单元挤在
top-k 边界上，浮点抖动改变选中结果）。按你最早定的第一条规矩，**默认 0（关闭）**，
代码保留、可选项。

所以 local3d 这一条**不照搬**，理由记在这里，不是漏做。

## 十四、born-wired-cortex 的"一拍"（读了 `model/主循环_完整的一拍.py`）

它的顺序（文件头写得很清楚）：

1. 时间往前走一格（时钟）；
2. 外界 → 视觉/听觉；身体 → 本体/平衡；
3. 三路 + 运动皮层 → 前额叶网 → **前额叶皮层（再压一次）**；
4. 前额叶 → 天生互惠返回线 → **送回视觉/听觉/运动**（"在心里看见画面"）；
5. 整片皮层走一拍：本能连接 + 赫布学习，算出这一拍谁亮；
6. 运动记忆区（时间神经元）→ 运动皮层 → 肌肉；
7. 赫布学习：这一拍和下一拍之间，谁跟谁一起亮了。

对照我们的单拍（`agi/loop.py`）：

| 步 | 它 | 我们 |
|---|---|---|
| 1 | 时钟先走 | 没有时钟（按你的要求不做时间区） |
| 2 | 感觉 → 各区 | 编码 → 输入层 ✓ |
| 3 | 三路 + 运动 → 前额叶 | 各区 → 专线 → 中继 → 前额叶 ✓ |
| 4 | 前额叶 → 返回线 → 感觉区 | 同样在**同一拍内**完成 ✓ |
| 5 | 整片皮层一拍 | 一次 `step()` ✓ |
| 6 | 运动记忆 → 运动皮层 → 肌肉 | 力度档 → 肌肉 ✓ |
| 7 | **同一拍共亮**才学 | **上一拍→这一拍**才学（按你的"先亮后亮"） |

**唯一实质差别**：它第 7 步用的是"同时亮就加强"，我们按你的要求改成"有先后才加强"。
这是你明确纠正过的，保留我们的写法。

另外它把"前额叶自压"写成**旋钮**（环境变量），并注明"这不是架构的一部分"——
和我们把 top-k 当调制手段是同一个态度。

## 十五、born-wired-cortex 的皮层连接网（读了 `model/皮层连接_cortex_links.py` 文件头）

这是它最核心的一张网：**本能连接和赫布学习在同一张网上**。

### 出生连接（写死在文件头，可调）

| 项 | 值 |
|---|---|
| 每个神经元出生带几条兴奋入边 | **100**（其中 50% 跨区、50% 本区） |
| 出生权重上限 | 0.15（"模糊但有大致方向"） |
| 标为"固化"的比例 | **30%**（基本一辈子不变） |
| 每个神经元出生带几条抑制边 | **100**（50% 就近、半径 24；50% 全脑随机） |
| 带去抑伙伴的神经元比例 | 25% |
| 哪些区不接收随机兴奋 | 运动、运动记忆、多巴胺、触觉（"运动皮层是输入层"） |

### 学习规则（同一张网上）

1. 两拍里一起亮 → 兴奋直连加强；**新长出的直连 = 绕过前额叶的短路**；
2. 一个亮、另一个不亮 → **亮的一方对它的抑制变强**（越无关越互相抑制）；
3. 总是一起亮 → 它们之间的抑制变弱、去抑制变强；
4. 亮着却带不亮对方 → 这条连接慢慢变弱；
5. 目标早就在亮、源才亮（没用上）→ 也慢慢变弱（默认关）。

它明确写了**没有**：海马索引、汇合细胞长程线、专注闸门。

### 对照我们

| 项 | 它 | 我们 | 判断 |
|---|---|---|---|
| 出生入边数 | 100/神经元 | 8~9（就近 + 自身） | 它是随机图，我们是局部链；两种取向 |
| 抑制 | **每个神经元 100 条抑制边** | 没有（只有运动区 I/D + top-k） | **这是你原话里的机制，它实现了** |
| 固定/可塑比例 | 30% 出生即固化，其余可塑 | 只有 group 40 可塑，其余全固定 | 我们的"固定"比例高得多 |
| 学习规则 | 含"带不亮对方就变弱"、"没用上就变弱" | 只有衰减 + 凹增长 | 可借鉴 |
| 区与区直连 | 出生就有 50% 跨区 + 学习中长出短路 | 483 条固定跨区 | 我们的跨区少，且不可学 |

**最有价值的一条**：它第 2 条规则——"一个亮、一个不亮 → 亮的对不亮的抑制变强"——
正是你说的抑制伙伴机制，而且它用的是"实际没一起亮"这个信号，不是随机采样。
我之前那版互抑制用随机采样，所以无效；照它这样写才有意义。

## 十六、born-wired-cortex 的本能表（读了 `model/本能工具_instincts.py` 文件头）

它遇到的真问题：**不能按输入编号写本能**。实测满屏红时，皮层亮在"输入层红色编号区"
的比例 6.1%，碰运气 6.7%——等于没有。但"满屏红"和"满屏蓝"的皮层模式只重叠 8 个细胞，
说明皮层分得清颜色，只是**认不出编号**。

它的三步走：

1. **标定**：给模型看一个例子（满屏红），记下皮层哪些细胞亮了，起个名字，存进 JSON；
2. **写本能表**（一行一条，用名字）：
   `视觉:红 -> 运动:肌肉组0  1.0  是`
3. **装**：把每条规则展开成一根根连接，写进皮层网。

### 对我们最有用的启示

我们 p9 的"一次学会"其实就是它的第 1+3 步：先记下画面 A 亮了哪些单元（=标定），
再把它们连到力度档（=装）。**差的是"名字"这一层**——没有名字，就没法写"规则表"，
只能每次跑一遍再连。

所以融合的下一步很清楚：加一层**"概念名 → 单元集合"的标定表**（存文件），
本能/示范/外部模型都用"名字"写规则，装的时候再展开成连接。
这正是你说的"一个神经元就像一个字"的工程化用法。

## 十七、概念名表（P11，2026-10-22）

补上"标定 → 起名 → 存盘 → 按名装规则"这一层（`agi/naming.py`）：

| 步骤 | 结果 |
|---|---|
| 标定"场景A"/"场景B" | 660 / 654 个单元 |
| 存成 JSON | 成功 |
| 用名字装规则（只用各自独有的单元） | 62,568 条边 |
| 点 A / 点 B | 0.57 / 0.70 |
| **新开一个脑子、只读名字文件重装** | **0.57 / 0.70（完全一致）** |

所以名字表是可持久、可复现的：以后示范、本能、外部模型都可以用"名字"写规则，
不用每次跑一遍再连。

小偏差：点 A 得到 0.57 而不是 0.50——因为 A 的提示还会经过中继/回程给力度细胞
一点额外驱动。这是"读出不是纯净总线"的表现，不是名字表的问题。

## 十八、按 bwc 规则重做抑制伙伴（2026-10-22，第四阶段第 1 步）

规则照着它写：A 亮、而 **A 自己的实际目标 B 没亮** → 加强 A→B 抑制，同时削弱 A→B 兴奋。

实测（2 个种子，800 拍）：

| 设置 | 只给 A 时含 B | 抑制边 |
|---|---:|---:|
| 关闭 | 0.54 / 0.48 | 0 |
| **开启** | **0.38 / 0.28** | ~20 万 |

**变差了**。原因很清楚：在我们的架构里，"目标没亮"大部分不是"没关联"，而是
**top-k 竞争没选上它**；这条规则把"竞争失败"当成"关联不成立"去惩罚，结果把真的
联想也削掉了。

bwc 能用这条，是因为它每个神经元有 100 条入边、共亮式学习，"没亮"信息量大；
我们是稀疏 top-k，"没亮"几乎是默认状态。

**结论**：规则实现正确，但在当前架构下有害，默认关闭。要用它，得先解决
"竞争失败 ≠ 无关联"这个混淆（比如只在"目标本轮根本没被任何输入驱动"时才罚）。

## 二十、为什么现在离不开 top-k（2026-10-22，回答"架构本身不就是稀疏码"）

实测三种做法：

| 做法 | 前额叶活跃 | 同图一致 | 近似 | 异图 | vision.L5 亮 |
|---|---:|---|---:|---:|---:|
| **top-k（现状）** | 671 | 是 | 0.91 | 0.22 | 2,078 / 15,360 |
| 去掉 top-k（门槛仍为 0） | 1,044 | 是 | 0.93 | 0.27 | **15,357 / 15,360（几乎全亮）** |
| 去掉 top-k，门槛=各自驱动 90% 分位 | 48 | 是 | 0.61 | 0.02 | **0 / 15,360（全灭）** |

**结论**：现在层内的驱动分布太"平"——随机均匀权重 + 8 个邻居，让每个神经元收到的
输入总量差不多，差别只来自输入图案本身。所以门槛要么几乎全过、要么一个都过不了；
能稳定给出"稀疏但随输入变化"的码的，只有 top-k。

**要真正做到"架构本身稀疏"**，得先把驱动的**对比度**做出来，而不是靠名额硬切。
最直接的一步：权重不要用均匀分布，改成**对数正态**（少数强连接 + 多数弱连接），
让不同神经元的驱动天然拉开差距；然后再试门槛稀疏。
这条记下来，作为下一步。

## 二十一、对数正态权重 + 门槛稀疏的实测（2026-10-22）

| 设置 | 前额叶 | 同图一致 | 近似 | 异图 | vision.L5 |
|---|---:|---|---:|---:|---:|
| 对数正态权重 + 门槛 80% 分位（无 top-k） | 113 | **否** | 0.75 | 0.04 | **0 / 15,360** |

还是不行：L5 全灭、同图不一致。**门槛稀疏在这套引擎里就是立不起来**——
驱动值彼此太接近，门槛卡在中间时，浮点抖动和逐拍波动都会翻转结果。

## 我认为真正对的方向（不是调权重）

链式库之所以天生稀疏，靠的是**成对神经元**：每个特征一对（正/负），每拍**恰好一个亮**。
一亿个神经元也只有一半亮，而且计数恒定——**根本不需要 top-k**。

我们现在只有 L1（温度计档位）是成对的，L2~L5 和前额叶都不是。所以：
- 要么把成对竞争推广到每一层（神经元数翻倍，PFC 5.2 万 → 10.5 万，仍在预算内）；
- 要么继续用 top-k。

这不是权重能调的，是结构选择。我建议前者——那才是"架构本身稀疏"。

## 二十二、成对竞争在 L5 上的实测（2026-10-22）

做法：把 L5 的神经元按 (2i, 2i+1) 配成对，每对只留驱动大的那个。

| 指标 | 结果 |
|---|---|
| 每场景亮的个数 | **7,680 / 15,360（恰好一半，计数恒定）** |
| 近似图重合 | **1.00** |
| 完全不同图重合 | **0.99** |

**计数问题解决了，但区分度没了**：三张完全不同的图，选出来的半边几乎一模一样。

原因：去掉 top-k 后 L5 已经**饱和**（15,357/15,360 都在 0.97 附近），驱动差异只剩一点点，
所以每对里永远是同一侧赢——码不再随输入变化。

**所以现在卡住的不是"用不用 top-k"，而是"层内有没有分级区"**：
- 有 top-k：只有前 k 个被选中，才有区分度，但名额造成竞争假象；
- 没 top-k：全饱和，没有区分度；
- 门槛：立不起来（前两轮实测）。

三者都试过了。下一步要么接受 top-k（并修它的副作用），要么从**输入端**解决饱和
（比如让 L1 的温度计更细、或减少层数让信号不被放大到饱和）。

## 二十三、引擎记录"上一拍驱动"（2026-10-22）

`engine.last_drive`（与神经元同长，下一拍会被覆盖）。实测 tiny 规模：26,290 个值，
其中 2,256 个为正。

**下一步（规则改写）**：

  `目标在 cur 里没被选中 且 last_drive[目标] <= 0`（即根本没被驱动）；
- 只用后者时才加强抑制、削弱兴奋；
- 再跑 p8 的"只给提示"测法，看会不会像粗版那样把联想削掉。

这一步还没做，不记成完成。

## 二十四、抑制伙伴：三种判据都试过，结论是"在我们这儿不适用"（2026-10-22）

| 判据 | 结果 |
|---|---|
| ① 目标没被选中（粗版） | 联想从 0.54 掉到 0.38——把竞争失败当成了无关联 |
| ② 目标最近 3 段没亮过 | 0 条抑制边（触发不了） |
| ③ 目标这一拍驱动 ≤ 0（`last_drive`） | **0 条抑制边** |

③ 最接近正确，但结果说明：在我们这张网里，**每个前额叶单元每一拍几乎都有正的驱动**
（1:1 感觉线 + 学习边），所以"完全没被驱动"这件事根本不发生。

**结论**：规则实现正确，但在"稠密驱动 + 稀疏名额"的架构里没有适用条件；
bwc 能用是因为它每个神经元 100 条入边且有真正的零驱动状态。
第 4 阶段第 (1) 项按"已核查、判定不适用"结项，代码保留默认关闭。
