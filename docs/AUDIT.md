## 三、char-neuron-network / voice（联想与记忆）

| 思想 | 我们的实现 | 判定 |
|---|---|---|
| 一个单元 = 一个字/音（1:1 专用线） | 1:1 模式（`pfc_fan_in=1`） | ✅ |
| 凹形生长（越涨越难涨） | Δw = η·(1−w/w_max)^pow | ✅ |
| 稀疏 top-k 出边 | `topk_out=8` | ✅ |
| 整体降权 + 低于下限删除 | 每 2000 拍 ×0.995 | ✅ |
| 连接强度 ≠ 传播强度 | 扇出归一 + 锐化 + 枢纽抑制 | ⚠️ 有偏差，见下 |
| 全局阈值调控 | 分位数标定 + 增益 ±0.05 | ✅ |
| 动态抑制（每拍只留 k 个） | `pfc_topk=0.005` | ✅ |
| **特异性闸门（PMI）** | 已实现：`wp *= sigmoid(1.2·(PMI − 0))`，下限 0.12，共现计数 500 拍滑动衰减；单元测试通过 | ✅（本轮补） |
| 没有硬门，是抑制/兴奋群体的竞争 | I/D 是加法抑制，不是阈值开关 | ✅ |
| 有先后才加强（顺序赫布） | `min_change` 只在画面变时学；上一拍亮→这一拍亮 | ✅ |

### 偏差说明（为什么）

1. **两层权重**：原库是 `W^1.5 ÷ 出边和 ÷ 入边和`。我们最初照抄，实测联想只占前额叶驱动
   1.17%（因为这里还有一条 1:1 的感觉线，两份归一叠起来把联想压死）。现在改成
   "扇出归一 + 枢纽抑制（入边和超过下限才摊薄）+ 可调增益"。
2. **PMI 闸门**：已按原库补上（见上表），但实测功能上仍推不动联想（`docs/P1_R2_LOG.md`）。

## 四、你口头给的规则

| 规则 | 实现 | 判定 |
|---|---|---|
| 记忆 = 前额叶神经元之间的连接，不是外挂模块 | 没有 memory 模块；group 40 就是它 | ✅ |
| 连接有先后（不是同时活跃就加强） | 顺序赫布 + `min_change` | ✅ |
| 有些连接天生难改、有些容易改 | 出生接线全部冻结，只有 group 40/41 可塑 | ✅ |
| 回程只让最强通过、随思考焦点移动 | 抑制细胞广撒网读前额叶、压住不够强的回程线 | ✅ |
| 回程亮过就被压住，不会来回激 | 回程中继习惯化 | ✅ |
| 两套控制互相竞争是**涌现现象**，不要专门写机制 | **已删除**上轮自作主张的"反射通路 + 压制细胞"；只保留出生接线（不可改）和抑制规则 | ✅（本轮删） |
| 没有自/他模块、没有时间模块 | 都没有 | ✅ |

## 五、这一轮改了什么

1. **删掉**第二套控制的专用机制（`reflex_on` 通路、压制细胞、组 50/51）——按你的要求，
   那是涌现的，不该焊死。
2. **补上** `self_copy`（local3d 的自身拷贝），实测两项指标都略好，设为默认。
3. 重跑：`tests` 15/15、`check` 0 issues、地基体检 0.90/0.22、单拍 12.2 ms。

## 六、还没做到的（明说）

1. **PMI 特异性闸门**（用枢纽抑制近似）；
2. **结构可塑性**（增/删神经元）——只有接口，没接进流程；
3. 联想学习仍弱（点 A 命中 B 专属 8 个、乱点 1.6，且乱点会漂）；
4. 狗的"大脑控制"目前靠抄示范，不是学出来的。

### 有意偏差（都有实测量化的理由）

| 项 | 库里的写法 | 我们的做法 | 为什么 |
|---|---|---|---|
| 学习时机 | 上一拍亮→这一拍亮 | **只在码稳定下来之后**，学两次稳定码之间的转移 | 实测同一场景码要 ~10 拍才稳；逐拍学到的全是瞬态单元，B 专属单元入边 = 0 |
| 学习目标 | 这一拍所有刚亮的 | 只把**最近两段稳码里没出现过的**当目标 | 不这样，边摊到共享单元上，测不出特异性 |
| 两层权重 | ÷出边和 ÷入边和 | 扇出归一 + 枢纽抑制（有下限） | 照抄时联想只占驱动 1.17%，被 1:1 感觉线压死 |
| 力度档 | 亮 1→0 … 亮 8→满档（绝对计数） | 门槛按肌肉组大小归一 | 我们的肌肉组是 42 个成员，绝对计数对不上 |

### 复查后仍然成立的不变量

- 每层每拍亮几个恒定；温度计每档恰好一个；五区都进额叶；前额叶内部 0 连接；
- 回程 ≤ 前向一半、不落 L1、门槛可达；
- 力度档门槛单调；I/D 门控符号正确；
- 单拍 10.3 ms（预算 20），Go2 闭环 10.2 ms 站得住。

### 还没做到的（明说）

1. PMI 闸门和枢纽抑制在"联想很稀"时会把权重压到很低（实测 0.02/边）；
2. 联想只能"调制"，因为在固定 top-k 预算里和感觉输入抢名额（回忆发生了，但被挤压）；
3. 结构可塑性有接口，但"什么时候增/删"还没接进流程。
