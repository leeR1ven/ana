# 路线图：从空框架到能操纵机器狗

每一阶段都写清**入口、判据、失败时的回滚**。没到判据就不进下一阶段。

---

## P0 · 空框架（已完成）

**做什么**：五种感觉 + 25 层链 + 1:1 专用线 + 前额叶（内部 0 边）+ 回程 + 运动区分档门控 + 自检 + 50 Hz 循环。

**判据**（已过）：
- `python -m agi check --preset xl` → 0 issues；
- `tests/test_ana.py` → 13/13；
- 单拍 ≤ 20 ms（xl：均值 9.3 ms，p95 13 ms；`large` 11.7 ms）；
- 前额叶内部边 = 0、可塑边 = 0；
- 温度计每档恰好一个亮；每层 top-k 精确；1:1 前额叶每个单元恰好一条入线。

**已知没做**：不会想、不会学、不会走。

## P1 · 让前额叶之间长出连接（记忆/联想）

**入口**：`PlasticRule(PlasticConfig(enabled=True, ...))`，喂**有时间的序列**。

做法：
1. 用虚拟身体/合成场景生成"有意义的时间序列"（比如：听到某个音 → 转头 → 看到某个色块；
   或者固定几个物体的注视序列）。关键是**有先后结构**，不是随机帧。
2. 每拍把前额叶活跃集合交给 `rule.apply(engine, cur)`；它按"上一拍亮 → 这一拍亮"长有向边。
3. 每 N 拍看一次：边数、平均权重、每个单元出度分布、`topk_out` 是否被顶满。

**判据**：
- 边数从 0 单调长到 10⁴–10⁵ 量级且不爆（单拍 > 16 ms 就算爆）；
- 同一序列重复 20 次后，**后一个刺激能单独激活前一个刺激的神经元**（重激活率 > 随机基线 + 3σ）；
- 前额叶活动在刺激撤掉后还能维持 2–5 拍（自持），但**不会自转**（无输入 20 拍内退回）；
- 不同序列的最终 PFC 码余弦 < 同序列的（分离度）。

**失败时的回滚**：先把 `eta` 减半、`topk_out` 减到 4、加整体降权频率；
仍爆就临时加"前额叶动态抑制"（每拍只留最强的 k 个，char-network 的做法），
但**只作为限幅器**，不替代连接学习。

## P2 · 让运动区学会用这些连接

**入口**：前额叶运动相关组 → 力度档这条链已经通了，但权重是随机出生的。

做法：
1. 先用**已有的出生接线**跑闭环，记录"哪些前额叶组合 → 哪些肌肉出力 → 身体发生了什么"；
2. 用顺序赫布加强"意图组合 → 运动组"的边（group 5 的可塑版本），
   奖励不是外部给的，而是"动作产生了预期感觉"（感觉副本 = 下一拍的输入）。
3. 保持 I/D 门控不变：学的是"什么时候该动"，不是"绕过门控"。

**判据**：
- 虚拟身体能从"乱走"变成"朝目标走"（500 拍内距离下降 > 50%，且不翻车）；
- 关掉前额叶（或切断 group 30）后行为退化到随机——证明是脑在控制，不是底层反射；
- 门控仍然有效：给强触觉时动作被压住。

**失败回滚**：只保留 group 5 的可塑性，不动区内链和回程；把学习率降到 1/4。

## P3 · 接宇树 Go2（MuJoCo）

**入口**：写 `bodies/go2.py`，实现和 `VirtualDog` 同样的两个方法（`observe()` / `step(forces)`）。

要点（按已有模型 `C:\mujoco_models\unitree_go2`）：
1. **力矩电机**：12 个电机 `ctrlrange` 见 go2.xml（髋 ±23.7、膝 ±45.43）。力度档 0..1 → 力矩必须经过
   一层"脊髓"：PD 站立保持 + 髋/膝映射 + 平衡反射。**不要把力度档直接当力矩**。
2. **时钟**：物理 500 Hz（每拍 10 个子步），大脑 50 Hz。子步里只跑 PD/反射，不跑大脑。
3. **感觉**：IMU（四元数/陀螺/加速度）→ 平衡区；12 关节角/角速度 → 本体区；
   4 足接触 → 触觉区；相机（可选）→ 视觉区（先降采样到 36×36）。
4. **安全**：力矩限幅、关节限位、跌倒检测（高度 < 0.15 或 |roll|>0.8 就松力）。

**判据**：
- 站立 10 s 不摔（高度 0.22–0.28，roll/pitch < 0.15）；
- 原地踏步 200 拍不摔；
- 前额叶切断后站不住（证明是脑在维持，而不是纯 PD）；
- 单拍总耗时（脑 + 物理子步）≤ 20 ms。

**失败回滚**：先只做"站立"（不接视觉），确认 PD + 平衡反射能稳住，再接大脑。

## P4 · 训练/测试协议（长期）

- **训练**：把真实/仿真经历录成序列（感觉 + 动作 + 结果），按 P1 的规则长边；
  定期做"睡眠"（整体降权 + top-k 剪枝 + 重放）。
- **测试**：新起点、新组合、切断某条通路，看行为是否退化到对应水平——
  区分"记住了"和"碰巧"。
- **规模**：先横向扩前额叶（1:1 时扩层），再扩 PFC 出度（top-k 8→16），
  每次都用 `bench` 守 20 ms 预算。
