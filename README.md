# 关联神经元架构（ANA）· v0 空框架

> 一个纯神经元、无梯度、无反向传播的架构骨架。
> 现在只有"出生接线"：**前额叶内部连接数 = 0**，记忆/联想的位置留好了，但一条边都没长。
> 还没接机器狗。

> **先看 [`docs/STATUS.md`](docs/STATUS.md)**：现在能做什么、不能做什么、每个数字怎么复现。
> 一句话：框架完整可自检、狗接上了能站能按画面倾、联想能长出来但还弱。

## 联想（记忆）现在到什么程度

- 前额叶内部连接默认 **0 条**（v0 只有出生接线）；
- 打开顺序赫布后，**看 B 时点 A 比点 C 多抬高 B 专属单元 +0.020**（3/3 种子，
  不学习时 −0.005）——这是第一个有对照、可复现的联想结果；
- 回忆是发生了，但它跟感觉输入抢同一份 top-k 名额，净增量很小：
  补全实验为负，因为 top-k 预算固定，点 A 会挤掉 B 的名额。
- 细节与全部数字：`docs/P1_R2_LOG.md`；定性：`docs/STATUS.md`。

## 一句话

感觉 → 每区一条链（L1 ON/OFF + L2–L5，固定权重、就近局部、每层精确 top-k）
→ 每层用 1:1 专用线经两级中继送进前额叶（前额叶每个神经元 = 一个"字"）
→ 回程只做调制 → 运动区按"亮几个力度神经元"分档出力，抑制/去抑制门控。

前额叶神经元之间**现在没有边**。以后训练时，靠"先亮 → 后亮"的赫布规则
让它们之间长出有向连接（group 40），那才是记忆和联想开始的地方。

## 实测规模（这台机器：i5-12600KF / torch CPU / 2 小步每拍）

| 预设 | 视觉 | 神经元 | 边 | 单拍 | 说明 |
|---|---|---:|---:|---:|---|
| tiny | 8×8×3 | 26k | 97k | 2.0 ms | 秒级自检 |
| full | 32×32×3 | 299k | ~610k | 8–9 ms | 保守实时 |
| **xl（默认）** | **36×36×3** | **373k** | **757k** | **9–11 ms** | 20 ms 预算下一半左右 |
| large | 40×40×3 | 456k | 1.12M | 11.7 ms | 上限（加联想边前） |

`demo` 是闭环 + 存遥测，比纯 `bench` 慢几毫秒；p95 会到 15–25 ms（这台机器有后台负载）。

## v0 里有什么

- **五种感觉**：视觉 36×36×3、听觉 32 段×4 帧、触觉 20、本体 36、平衡 10；
  每通道温度计正反编码，**每对恰好亮一个**，活跃总数恒定（不会有的图很亮、有的很暗）。
- **25 层**：每区 L1（ON/OFF）+ L2–L5，越靠近前额叶越多；每层精确 top-k（40/30/20/10%）。
- **1:1 专用线**：每个层神经元一根线 → 两级中继 → 前额叶**同一个**神经元
  （身份证一一对应，不重复、不漏）。
- **前额叶**：65k 个单元，每层一组；按"常亮/常灭不送额叶"筛掉 82% 后保留 **11,748** 个
  （筛选按虚拟身体实际经历的活跃率 2%–60% 判）；内部 **0 条边**。
- **回程**：前额叶一组 → 两级回程中继 → 按位置送回本层（不落 L1），边数 ≤ 前向一半，只做调制。
- **运动区**：运动相关前额叶组按肌肉切分 → 力度神经元按"亮几个"分档；
  I（抑制）/ D（去抑制）门控；触觉有直接反射抑制。
- **联想插槽**：`PlasticRule`（顺序赫布 + 凹增长 + top-k + 整体降权 + 两层权重），
  默认 `enabled=False`，v0 边数恒为 0。打开后的第一组基线数据见 `docs/P1_LOG.md`。

## v0 里**没有**什么（故意的）

- 前额叶内部联想边（group 40）——0 条；
- 任何可塑边（group -1）——0 条；
- 海马体、独立记忆模块、自/他标记、"时刻"通道——都没有，也不会加：
  记忆是前额叶神经元之间的连接，不是外挂的仓库；
- 机器狗：**已接**（`agi/body_go2.py`），能站住，但站姿是 PD 撑的，大脑还没学会控制；
- 视觉不是相机：是 36×36 的合成画面；接真机要换 `world.py`。

## 诚实说明

- 这是**框架**，不是能力：现在的前额叶只反映当前输入，不会"想"，因为没有内部连接；
- 出力是"亮几个力度神经元"的计数映射，没有经过运动学习，虚拟身体只会乱走；
- 单拍耗时会随机器负载波动，p95 可能超过 20 ms；要绝对稳就降到 `full` 或 `--substeps 1`。
